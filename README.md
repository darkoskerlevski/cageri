

# 🕰️ Цагери — Значење на часот

Модерна веб-апликација за толкување на значењето на поклопените сказалки (**цагери**), инспирирана од македонски народни верувања. Апликацијата во реално време покажува што значат бројките на часовникот, според денот во неделата.

## ✨ Функционалности

- 🕒 **Часовник во реално време** — прецизен дигитален приказ на часови, минути и секунди
- ⚡ **Активен цагер** — автоматски приказ на тековниот цагер кога сказалките се поклопени
- ⏱️ **Бројач до следниот цагер** — колку минути/секунди остануваат до следниот момент
- 📋 **Целосна листа** — преглед на сите значења за секој ден, со нагласување на активниот/следниот цагер
- ❤️ **Омилени** — зачувај ги своите омилени цагери (зачувано во `localStorage`)
- 📤 **Споделување** — сподели цагер преку Web Share API или копирај го во клипборд
- 🌙 **Темна тема** — автоматски ја почитува системската поставка, со можност за рачно менување
- 📱 **PWA** — инсталирај ја апликацијата на телефонот за офлајн пристап
- ♿ **Пристапност** — ARIA улоги, `aria-live`, поддршка за тастатура

---

## 🛠️ Технологија

- **HTML5** — семантички markup со ARIA атрибути
- **CSS3** — CSS варијабли за теми, Flexbox/Grid, `prefers-color-scheme`
- **Vanilla JavaScript** — без никакви external библиотеки
- **Web App Manifest** — за PWA инсталација
- **Service Worker** — за офлајн поддршка (cache-first стратегија)

